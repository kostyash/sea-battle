# Морской бой — план работ

Состояние цикла. Один проход — один невыполненный пункт сверху вниз.
Галочка ставится только после того, как ворота реально прогнаны командой.

## Ворота

Из `C:\sea-battle`:

| Команда | Когда |
| --- | --- |
| `npm run build` | каждый проход; exit 0, без предупреждений |
| `npm test -- --run` | каждый проход; всё зелёное |
| покрытие ≥ 95% строк/веток на `src/app/domain/**` и `src/app/ai/**`, ≥ 70% общее | каждый проход после появления этих каталогов |
| `npm run test:sim` | ворота фазы 2 и финальные ворота (медленно) |

Прогон тестов и ворота покрытия разведены намеренно: `npm test` падает только на
упавших тестах, пороги проверяет `npm run test:coverage`. Иначе ни один пункт до
фазы 3 нельзя закрыть — проценты физически недостижимы, пока нет ни домена, ни
тестов хранилища. Ворота покрытия красные до конца фазы 3, и это записано ниже
в журнале, а не спрятано.
